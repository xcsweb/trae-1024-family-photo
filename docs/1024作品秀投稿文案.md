# 标题（复制这一行）

【1024Builder作品秀】TRAE 社区 1024 全家福：600 位 Builder 拼出你的名字，每个人都能当一次主角

# 正文（以下开始复制）

我把 TRAE 社区 600 位 Builder 的头像和昵称，做成了一张能搜到自己、能一键变阵、能导出保存的 1024 全家福。它是一份给社区的节日礼物，也是 1024 这天，社区一起留下的合影。

![image|690x327](upload://【新截图：倒计时全屏 · 打开就是这一屏】)


## 这到底是什么

「TRAE 社区 1024 全家福」是一个纯前端、零依赖、双击即开的单文件网页。打开先是 600 位 Builder 的头像拼成的倒计时；切到「星座」就能看到他们散在夜空里，像一片星空；每个人只给你一张头像，但彼此之间用绿色的线连着，连成一张社区网。

它不是一张静态海报，而是一个能玩的东西：有搜索、有拖拽、有导出，还有「主角秀」——轮到谁，谁就站到 C 位。

![image|690x327](upload://【新截图：作品全貌 / 五种形态示意】)


## 五种形态，一键切换

顶部一栏按钮，随时切换：

- **倒计时**（打开就是这一屏）：600 个头像实时拼出距 1024 还剩的时间——超过 1 天显示「3天13时26分」，最后一天才出现秒。倒计时看久了，它会自己切到「主角秀」（下面单独讲）。**归零那一刻**全场点亮，画面直接落到「1024」，并且 **1024 当天一直放烟花**；这一栏不收起，而是改名叫「主角秀」——当天没有剩余时间可看，但搜自己、拼名字、拼脸照常玩。**1024 过完，它会自动变回「倒计时」，接着数下一个 10 月 24 日**。
- **星座**：头像像星星散在夜空，同一片区的人自动连成网（共 791 条连线），抬头就是你熟悉的社区。
- **地球**：600 个人均匀铺在一个球面上，可以拖拽旋转、松手后会慢慢自转；球面近大远小，转过去还能看到背面的人。
- **1024**：所有人瞬间归位，拼成巨大的「1024」点阵——这一天，属于每一个 Build 的人。
- **星流**：600 张头像先散成一片流动的星尘，鼠标划过会卷出涡旋；点一下，它们就收束成一幅画——可以是任意文字、你上传的任意图片，也可以直接选一幅名画。**十几秒，600 个人一起重画一次梵高。**

## 主角秀：轮到谁，谁就是主角

这是这个作品里我最喜欢的一部分。**600 张头像不只是装饰，它们会一起把一个人「拼」出来。**

- 倒计时界面每 8 秒会自己切一次主角秀：先用这 600 张头像拼出那位 Builder 的**昵称**，停留约 2.8 秒让你看清，再散开重排、拼成他的**头像**停约 2 秒，如此来回循环——每张头像都被挑到它颜色最接近的那一格，600 张脸合起来，就是主角的那张脸。
- 旁边的卡片会写清他是谁、以及**「TA 做了什么」**：头衔徽章、他最近发过的帖子标题和互动数据；如果那篇正好是 1024Builder 作品秀的参赛作品，会特别标成「参赛作品《xxx》」。
- 想指定谁当主角：右上角搜昵称，搜到之后点「让 TA 当主角」（或者直接按回车），他就锁定在 C 位不再轮播；点画面里任意一张头像，可以立刻换成那个人。看完点「退出主角秀」回到倒计时。

## 怎么玩（30 秒上手）

1. **找自己**：在右上角搜索框输入昵称或用户名，头像会高亮、页面自动定位过去。地球模式下，球体会自动把那个人转到正面，一眼就能看见。
2. **看细节**：鼠标悬停任意头像，弹出昵称、用户名和发帖数。
3. **拖着玩**：地球模式下按住拖动，即可旋转查看。
4. **看主角秀**：在倒计时这一屏等着看它自己轮播，或者搜到自己后点「让 TA 当主角」，看 600 张头像怎么拼出你。
5. **带走它**：点「导出合影」，按当前形态生成 2 倍分辨率 PNG，直接保存、发群。

## 入镜的 600 位 Builder

这 600 位，是 1024 前后活跃在社区的 Builder——[玩法一「1024 Builder 集结」](https://forum.trae.cn/t/topic/325833)盖楼帖的回帖者、[玩法二「1024Builder作品秀」](https://forum.trae.cn/tag/109-tag/109)下作品帖的作者与回帖者，以及社区里持续发帖分享的一批人。

四路整理下来共 1104 位，取前 600 位入镜。头像统一按 96px 展示，保证在星空中既能看清、又不喧宾夺主。


## 技术实现（纯前端）

整个作品是一个零依赖的单文件 HTML——没有框架、没有后端、不引入任何第三方库，双击即开、离线可用。核心是三层叠在一起的渲染：

- **背景层（Canvas 2D）**：按屏幕尺寸实时绘制星野——底色渐变 + 三处星云辉光 + 上千颗随机星点（含十字星芒）；地球模式再叠一个带大气辉光和边缘光的球体。按 devicePixelRatio 缩放，高分屏不糊。
- **连线层（SVG）**：星座模式下用矢量贝塞尔曲线绘制 791 条连线，缩放不失真，悬停时对应连线高亮。
- **人物层（DOM + transform）**：600 个头像用绝对定位 + `translate()` / `rotate()` / `scale()` 摆放，形态切换靠 CSS transition 做飞散重排动画。

五种形态的排布算法：

- **倒计时**：把当前剩余时间格式化成 `3天13时26分` 这样的字符串，渲染到离屏 Canvas 采样出笔画像素，二分搜索出刚好容纳 600 个头像的格子尺寸；超过 1 天只精确到分，最后一天加入秒，归零后落回「1024」纪念态。
- **星座**：先按人数在画布上撒若干聚类中心（带抖动的网格），每个人沿螺旋线散到所属中心周围，再对每个点找最近的 2 个同伴连线成网。头像刻意留小（约 12–18px），让 600 颗星之间的连线看得清。
- **地球**：用 Fibonacci 球面算法把 600 个点均匀铺在单位球上，渲染时按当前旋转角做正交投影，越靠前越亮越大（z 值映射缩放与透明度），按深度排序控制遮挡。
- **1024**：把「1024」渲染到离屏 Canvas 读出像素，二分搜索出刚好容纳 600 个点的格子尺寸，再等距抽样取点位。
- **主角秀（像素画人像）**：把主角的头像等比裁成方形、降采样成 25×24 的目标色块（正好 600 格），再把 600 位成员的头像各自降采样后按 32 级量化分桶、取像素最多的那一簇作为这人的**主色调**；然后逐格去 600 人里挑「主色调和目标色最接近」的那位放上去——颜色稀缺时就**复用一个成员头像占多格**（用「已用次数」做惩罚项，让常见色摊开、稀有颜色才复用）。整面墙的颜色**全部来自成员头像自己的主色调**，没有滤镜、没有蒙层，是实打实的像素画。名字阶段复用 1024 那套文字栅格化，把同一批头像先排成昵称，再动画过渡到像素网格——全程复用同一批 DOM 节点。
- **星流**：内置一套自己写的 2D 值噪声（不引任何依赖），由噪声梯度构造 curl 向量场，600 张头像沿场线漂移，再用每位成员的主色调在轨迹画布上叠一层点彩拖尾；鼠标位置注入一个会自然衰减的涡旋。收束时，把目标图（文字栅格 / 上传图片 / 名画预设）按 cover 裁切降采样成格网，再用和主角秀同一套「色差 + 亮度差 + 复用惩罚」的最近色匹配，让每个人去颜色最接近的那一格；格数超过人数时同一人可以占多格，精度分 **20×19 / 25×24 / 35×34 / 50×48** 四档。名画源图以 150×144 内嵌，运行时按档位降采样。
- **烟花**：归零后 16 发火箭从底部升空（带拖尾），到顶点爆裂成 70–130 颗火花，受重力下落、带阻尼衰减，用 `lighter` 合成模式叠加出光晕；而且 **1024 当天（归零起算的这 24 小时）会一直放**。

交互部分：搜索在星座 / 1024 / 倒计时模式下滚动居中，在地球模式下反解目标点的球面坐标、算出最短旋转路径把球体转到正面；主角秀支持自动轮播、搜索锁定、点击换人、退出回落；导出用原生 Canvas 手动合成 2 倍 DPR 的 PNG。

## TRAE 在创作中做了什么

这次几乎全流程都是我和 TRAE 一起完成的：

- **前端实现**：三种叠加渲染层（Canvas 星野 / SVG 连线 / DOM transform 人物层）与形态切换动画；
- **布局算法**：文字栅格化 + 动态点阵倒计时、星座聚类散布 + 近邻连线、Fibonacci 球面 + 正交投影、主色调分桶 + 最近色配对的像素画人像；
- **数据抓取**：写 Node 脚本走论坛公开接口，抓 600 位 Builder 的头像、昵称、发帖数，以及每人近期主题帖的标题与互动数据，供「TA 做了什么」使用；
- **交互与导出**：搜索定位、地球自动转正、主角秀轮播 / 锁定 / 换人、2 倍 DPR 的 PNG 导出；
- **自测**：用无头浏览器自动化验收四形态渲染、拖拽旋转、搜索定位、主角秀、归零烟花与控制台报错。

## 关键提示词

这个作品最初的想法，就是几句话聊出来的：

> 「我想弄一个全社区的合影照。」

> 「天上的星星就代表一个人，头像分开但是又连线这种；要么就弄一个球形的地球，每个人分配一个地点，都站在地球上。」

> 「头像和昵称都要，希望支持快速搜索，能找到自己在哪里。」

> 「别用一长串数字，超过 1 天就直接显示几天、几小时、几分钟，这样一眼就能读完。」

> 「倒计时的时候或者搜到自己的时候，每个人都能成为主角，由社区成员的头像拼成他的头像或者名字，并在旁边写他做了什么。」

> 「用成员头像拼主角的时候，能不能先筛一下每个人头像的主色调，再拼到主角对应色调的区域？颜色少的话可以复用同一个头像。我想要的是像素画那种，不是滤镜那种。」

> 「最后倒计时完了，数字就变成 1024 了，倒计时那个页面就不需要了，直接跳到 1024 那个 tab，再放一个烟花特效；既然都到 1024 了，那就让烟花当天一直放。」

从「合影照」到「倒计时 + 星座 + 地球 + 星流 + 1024 + 主角秀」，几百行代码，基本就是这样对话出来的。

## 一些数字

- 入镜 Builder：**600** 位
- 星座连线：**791** 条
- 形态：**5** 种（倒计时 / 星座 / 地球 / 星流 / 1024）+ 倒计时内置的「主角秀」
- 星流名画预设：**8** 幅——梵高《星月夜》《向日葵》、葛饰北斋《神奈川冲浪里》、修拉《大碗岛的星期天下午》、莫奈《睡莲》、蒙克《呐喊》、维米尔《戴珍珠耳环的少女》，以及官方 IP「TRAE 宝」
- 星流精度：**4** 档（20×19 / 25×24 / 35×34 / 50×48），人不够格子时同一成员可占多格
- 主角秀像素画：**25 × 24 = 600** 格，一格一人，颜色稀缺时同一人可复用占多格
- 渲染层：**3** 层（Canvas / SVG / DOM）叠加
- 单文件体积：**3.42 MB**，零依赖、双击即开、离线可用
- 头像尺寸：96px（星座模式约 **12–18px**，刻意留小，让 600 颗星之间的连线看得清）
- 归零后：倒计时这一栏改名为「主角秀」（不收起，主角秀照常玩），直接落到「1024」，且 **1024 当天持续放烟花**；**当天过完自动变回「倒计时」，目标滚到明年的 10 月 24 日**，作品不会「过期」
