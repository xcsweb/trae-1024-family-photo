## 0. 先定分工：抖音不是小红书的"转发区"

| | 小红书（主阵地） | 抖音（二次分发） |
|---|---|---|
| 流量逻辑 | 去中心化 + 搜索驱动（60%+ 来自搜索） | 中心化推荐 + 赛马，爆款周期约 **7 天** |
| 第一权重 | 封面点击率、收藏、评论、关注（CES） | **完播率**，其次转发/评论（权重高于点赞） |
| 内容形式 | 图文 9 图 + 长文案 | **竖屏短视频 15 秒–3 分钟** |
| 生命周期 | 搜索长尾，数月持续带量 | 7 天定生死，之后基本归零 |
| 起量特征 | 慢、稳、素人友好 | 快、猛、前 3 秒定生死 |

**结论：同一份素材必须做成两套内容。**小红书那篇 9 图长图文直接丢到抖音必扑——抖音不认文字，只认「前 3 秒那一帧」。

## 1. 抖音发布前：账号与主页（新号尤其重要）

- **一句话人设**：我是【身份标签】+ 帮【目标人群】解决【具体问题】+ 通过【差异化方式】。
  例：`我是 TRAE 社区的前端 Builder，帮社区的人找到自己在全家福里的位置，用零依赖单文件网页做的。`
- **主页四件套（抖音列）**：
  - 头像：高清真人或领域符号，风格统一；
  - 昵称：核心领域 + 细分场景，好记好搜（如「xcsweb 做点小东西」）；
  - 简介：「专注 XX + 提供 XX 价值 + 互动引导」，**不要留微信/外链**；
  - 背景图：放核心成果（如「已把 600 位社区 Builder 拼进一张全家福」），置顶 3 条代表作。
- **账号等级**：2025 年后抖音按 SABC 分基础流量，新号 = 低等级，基础播放少，所以**前 5 条内容尤其关键**。
- **养号 2–3 天**：每天刷同赛道 30 分钟并正常互动，让系统识别为「垂直领域真实用户」，别一注册就发。

## 2. 内容制作：把网页变成抖音能吃的竖屏视频

### 2.1 前 3 秒钩子（第一优先级）
抖音通用公式：**把最冲突 / 最炸裂 / 最反常识的一帧前置**。
本作品最炸的一帧就是：**600 张头像瞬间散开重排，拼出你输入的那个名字/那张脸**——这一帧必须是视频第 0 秒，不许有片头、不许有 logo、不许有"大家好"。

### 2.2 结构模板
`3 秒钩子 → 5 秒提问 → 10 秒福利/结果`，全程硬字幕 + 口播。

### 2.3 标题公式
抖音标题双引擎：**情绪断言型 + 利益/实用型**，并埋**疑问 / 数字 / 反常识**。
- 情绪断言型：「600 个人的头像里，藏着你的名字」
- 利益实用型：「90% 的社区人都不知道：你的头像在这张图里」

### 2.4 封面
竖版全屏（540×960 居多），共性 = **界面截图 + 大字行动指令**，高饱和、字大、一眼看懂玩法。
本作品封面建议：全家福截图 + 大字「找找你在哪」「搜昵称 → 600 张脸拼出你」。

### 2.5 BGM（分轨）
- 玩法 / 互动类：轻快电子、热门手势舞原曲（借势流量，如《绵雨摇》这类热曲）；
- 治愈 / 情绪类：钢琴 / 民谣轻音乐，低缓留白；
- 教程类：极轻或不用 BGM，突出人声。
选曲逻辑：**踩点优于旋律，BGM 是爆款关键项**。

### 2.6 时长（按目的分化）
- 玩法展示 / 反差钩子类：**10–20 秒**（吃完播）；
- 互动测试类：**15–30 秒**；
- 教程 / 技术拆解类：**60–120 秒**（吃收藏）。
新号前 5 条优先 **7–15 秒**，把完播率跑起来。

## 3. 三条可直接拍的选题（本作品专属）

**① 互动测试型（主推，题材17 方向）**
- 标题：《600 个人的头像里，藏着你的名字，敢不敢来搜一下？》
- 前 3 秒：手指在搜索框打字 → 回车 → 画面瞬间炸开重排 → 拼出那个昵称
- 结构：搜索定位（3s）→ 散开重排（5s）→ 拼名字 + 拼人脸 + 「TA 做了什么」卡片（10s）→ 引导「评论打你的昵称，我帮你拼」
- 时长 20–30 秒，玩法类轻快 BGM + 硬字幕

**② 玩法展示型（视觉冲击，主打 7 天爆款）**
- 标题：《我把社区 600 个人的头像，做成了一张能找自己的全家福》
- 前 3 秒：1024 点阵全屏 → 瞬间飞散变成星座/地球
- 结构：全貌飞行（5s）→ 星座连线（5s）→ 地球旋转（5s）→ 归零烟花（5s）→ 引导「搜自己」
- 时长 15–25 秒，史诗电子或治愈钢琴（按调性二选一）

**③ 技术/教程型（吃收藏与搜索，题材5 AIGC 方向）**
- 标题：《零依赖、单文件、600 张头像：这个网页是怎么做出来的》
- 前 3 秒：结果反差前置——「一个 2.8MB 的 HTML 文件，没有框架没有后端」
- 结构：痛点（多平台渲染卡顿）→ 方案（Canvas 星野 + SVG 连线 + DOM 人物层三层叠加）→ 关键算法（文字栅格化点阵 / Fibonacci 球面 / 主色调分桶匹配）→ 「存下吧，代码结构很少见」
- 时长 60–120 秒，口播 + 录屏，BGM 极轻
- 高频话题参考：#AI教程 #AI视频生成 #提示词 #aigc #打工人必备

## 4. 发布动作清单

| 项 | 做法 |
|---|---|
| **发布时段** | 早通勤 7:00–9:00、午休 11:30–13:00、**晚间高峰 20:00–23:00** |

## 5. 冷启动与放大

- **Dou+**：只投**自然流已经跑出来**的作品，内容差的不投。30 元 ≈ 1000 播放，先小额测款。
- **破 5000 播放** → 立刻做**系列续集**：「第 2 集：我把自己拼进了全家福」「隐藏玩法：点任意头像直接换主角」。
- **合拍 / 挑战赛**：参与官方挑战赛借流量池，与同量级账号合拍。
- **直播联动**：视频流量与直播互相引流。

## 6. 复盘指标与阈值（发布后 24h / 72h / 7 天各看一次）

| 指标 | 抖音合格参考 | 不达标怎么办 |
|---|---|---|
| **前 3 秒留存** | ≥ 40% | 换开头那一帧，把最炸的画面提到 0 秒 |
| **完播率** | 短视频 ≥ 30%–40%（爆文 > 40%） | 缩短时长、加快节奏、砍掉铺垫 |
| **点赞率** | > 3%–5% | 情绪共鸣不够，加反差/金句 |
| **评论率** | 互动率 < 5% 需在文末埋提问 | 加「你叫什么？我帮你拼」这类明确指令 |
| **涨粉转化** | 关注 / 播放 | 人设不清晰，优化主页与结尾引导 |

- 播放**持续低于 500** → 查是否限流、标签是否打乱、内容是否违规；
- 单条**破 5000** → 立刻做续集/二创，用爆款带后续流量。

## 7. 抖音红线（踩了直接压流量）

1. **站外硬导流**是重点打击对象：简介、评论、私信里别直接留微信 / 外链（作品 Demo 链接别硬贴，用「主页/评论区互动」软引导）。
2. **不刷量**：刷粉、刷赞、刷评论一律不要。
3. **不堆标签**：话题超过 5–6 个易触发限流。
4. **AI 批量生成的「超创」内容被限流**，平台鼓励原生真人内容 → 教程类最好真人出镜口播，别纯 AI 念稿。
5. **不发硬广、不搬运**他人素材；发布后不频繁改标题/封面。
6. **不要把抖音的做法搬到小红书**（反之亦然）——两套逻辑，混做必掉量。

## 8. 参考数据：与本作品最相关的三个抖音题材

### 题材17｜互动测试 / 玩法挑战（主推方向，20 条样本）
- 互动（有效 18 条）：**点赞中位 ≈ 46**，**评论中位 ≈ 15**，最高点赞 **15,341**、最高评论 **4,864**（两条都是「手把手教你怎么发作品提高跟拍率」的教程型）。
- 标题：普遍 **10–30 字**（教程类 30–60 字）；带数字约 30%、疑问句约 25%。
- 高频标签：**#抖音玩法合伙人计划（8 次）、#拍同款（6 次）、#心理测试（6 次）、#特效（5 次）、#盲盒（4 次）**。
- 开头钩子三型：直接互动指令型（"点击按钮开始 / 点左下角拍同款"）、悬念提问型（"你第一眼看到什么"）、教程收益型（"0 粉七天 2000+"）。
- 正文结构：测试类 = 情景引入 → A/B 选项 → 逐项解读；玩法类 = 特效展示 → 操作步骤 → 引导拍同款。
- 封面：竖版 540×960 界面截图 + 大字行动指令，高饱和、字大。
- 时长：测试类 15–30 秒、玩法展示 10–20 秒、教程 60–120 秒。

### 题材5｜AIGC / AI 生成内容（教程型方向）
- 标题带数字 **60%**，字数 **25–55 字**，高频关键词：AI 教程 / AI 短剧 / 提示词 / 即梦 / 工具。
- 开头钩子以**结果或反差前置**为主（"27 元 → 2 块""同事加班我下班""500 万播放 3 小时做完"）。
- 几乎全是**口播 + 录屏 + 硬字幕**，强调「可复制 / 可落地」。
- 时长：工具操作 2–5 分钟、行业分析 2–4 分钟、清单合集 1–2 分钟。

### 题材8｜科技 / 数码 / 新能源
- 标题公式 =「新品名 + 争议点」，结构 = 3 秒钩子放最反常识卖点 → 中段真机上手 / 实测对比 → 结尾购买建议；时长上手 30–60 秒、深度评测 3–6 分钟。
